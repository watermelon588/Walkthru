# Walkthru Launch Toolkit

Free Agensi skill pack. **Connected features require an existing Walkthru Plus account and a personal API key.** Report review also works with a Walkthru report or findings export you provide.

| Skill | What it helps you do |
| --- | --- |
| Walkthru Launch Reports | Review saved reports, plan fixes, request passive checks for authorized sites, compare reports, manage findings and check usage. |
| Walkthru AI Visibility | Read tracked AI answers, manage the questions Walkthru asks and request an updated batch. |
| Walkthru Monitoring | Review weekly checks, set up deploy checks and preview configuration fixes for a connected GitHub repository. |

Start with [setup](shared/setup.md). The [tool reference](shared/mcp-tools.md) lists all 26 tools registered by Walkthru. Connected actions go through Walkthru's hosted `/mcp` endpoint and use the caller's account permissions, plan and limits. Agensi delivers these instructions and examples to the agent.

Try asking, “Review my latest Walkthru report for my site. Show me the top three findings, the evidence for each, and how to check the fixes.”

Start browser journeys in the Walkthru Chrome extension. Once the report is available, this pack can read it. The MCP quote describes the available journey terms. GitHub actions require the Walkthru GitHub App to be available on the server and connected to the repository. AI answers, monitoring and usage detail depend on the features configured on the server.
